Your email signature

Emails Locus sends for you already carry this. To put it on emails you write yourself:

  1. Press Copy the signature below (or select the box and copy).
  2. In Gmail: the gear, See all settings, then Signature, Create new, name it "Mobius".
  3. Paste into the box, set it as the default for new emails and replies, and Save Changes at the bottom.
