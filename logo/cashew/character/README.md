# Cashew, the character

Rendered, not drawn. Cole rejected the hand-coded vector nuts (2026-10-11): "it looks drawn". These are
image-model renders of a glossy green cashew with a pale belly and two bead eyes, cut out onto transparent
PNGs, in the five states the apps use: rest, thinking, found (it found something), asleep (signed out), clear
(all clear). The logo is still the wordmark (../wordmark.svg) and the C icon (../mark.svg); the character
never appears on a CPA pack or a statement.

Files here are 200px cut-outs, fine for the ask bar (20px), the nudge card (48px) and the gate (96px).
Larger versions for the commercial land here under the same names at 1024px when exported.

Explorations: explorations.png (clay, glossy, flat). The glossy one was chosen.
