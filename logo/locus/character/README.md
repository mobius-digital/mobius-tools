# Locus, the character

Rendered in the same style as Cashew's character so the two read as one family: a glossy blue bead with a
pale face and a thin pale orbit ring (a locus is a point moving along a path). Five transparent PNG states:
rest, thinking, found (it found something), asleep (signed out), clear (all clear). The logo and app icon stay
the vector bead (../direction-2.svg, ../icons/); the character is the helper in the ask bar, the nudge card,
the morning strip and the commercial, never on a report or a client-facing document.

200px cut-outs today; larger versions under the same names later. the-pair.png shows both characters together.
