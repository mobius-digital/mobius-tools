# Mobius Tools

A collection of free, no-login tools built by [Mobius Digital](https://go-mobius-digital.com) for DTC (direct-to-consumer) brands.

These are simple, fast, browser-based utilities to help ecommerce and DTC teams make better decisions — no sign-up, no data leaves your browser.

## Tools

| Tool | Description |
| --- | --- |
| [ROAS Calculator](roas-calculator/) | Calculate return on ad spend, break-even ROAS, and profitability for your paid campaigns. |
