# Triple Whale BFCM Command Center (seen 2026-10-09 in Cole's account, Dartee)

An "app" under Custom Workspaces with two tabs: **Planning** (Active) and **Live Tracking** (Not set).
Planning is a 7-step guided build with a sticky left step list (How to use, Review historical baseline, Set goals &
channel budgets, Add campaign context, Configure live tracking, Connect Moby to Slack, Set up Competitive
Intelligence) and a "Get set up 0 of 7 complete" carousel.
- Historical baseline: pick last year's BFCM window (Nov 26 to Dec 3 2025), load: tiles (transaction revenue, orders,
  AOV, platform ad spend, blended ROAS), daily revenue table for those days, revenue by channel, top-selling products.
- Goals, budget & guardrails: up to 5 performance goals (metric + target), sale start/end, currency, timezone;
  paid media budget, then per-channel budget ($ or %), key metric + target, channel type; "$0 allocated" warning.
- Campaign context: key dates & milestones on a horizontal timeline ("What's happening around your sale?").
- Configure live tracking: alert thresholds (channel overspend % of daily budget, AOV floor, stock cover days...),
  "Moby's Live Tracking check" (checks goals, thresholds, pacing, channel performance once actuals load), Slack.
- Live Tracking tab (after setup): actuals vs plan pacing during the sale.
- Ships with automations: weekly planning reminder, daily 9am live performance review that recommends actions.
