Goals and ad calls

How Locus should judge an ad set, written as a DTC media buyer would run it. Today a row on Calls says Cut or Scale from one or two rules. This plan gives each brand one goal that decides, keeps every other number as a guardrail, and shows the buyer the evidence instead of a verdict when the numbers disagree.

1. One main goal per brand

Set in Brand settings, Goals and ad rules. Only one goal decides a call. Pick the one that matches how the brand makes money.

Main goalUse it whenExample
New-customer cost (nCPA)Customers come back and the business is built on buying first orders (LTV over CAC).Lucky Golf, Grunk
Blended MERThe brand runs on total store revenue over total spend and does not split new from returning.Brands mid-scale, many channels
ROASOne-purchase products, where the first order is the whole value.Novelty and gift products
Cost per sale (CPA)A fixed price point, so every sale is worth about the same.Single-product brands

2. Everything else is a guardrail

  • A guardrail never decides on its own. If ROAS is the main goal and you also type a CPA, that CPA is a ceiling: a set only gets flagged when it breaks it.
  • An empty field does not count. Put in only a CPA and Locus judges on CPA alone. That is your rule: "if I only put CPA, it goes off CPA".
  • Blended MER is always the brand's guardrail on Today and Month, whatever the main goal, because it is the number that pays the bills.

3. Platform goals are separate from blended goals

Meta and Google each count their own sales, and their cost per sale runs far above the blended one (Bonk: about $25 blended against $58 on Meta's last click). Judging a Meta ad set against a blended goal cuts working ads. So each platform gets its own goal in the same metric as the main goal. Locus suggests it from the brand's goal times that platform's measured gap over the last 90 days, and you approve it. Ad set calls use the platform goal; Today, Month and P&L use blended.

4. The ad set panel

Tap an ad set on Calls. The panel shows every number against its goal, which numbers argue for keeping it and which for cutting, and a call only when they agree.
